# Portfolio

Web制作・JavaScript実装の学習成果をまとめたポートフォリオサイトです。  
HTML / CSS / JavaScript / jQuery を中心に、LP、カルーセル、住所API連携、簡易計測デモなどの制作物を掲載しています。

## 公開URL

https://aktouch.github.io/portfolio/

## 掲載している制作物

### 1. Schoolbag Remake LP

ランドセルリメイクサービスを想定したLP・デザインカンプ・バナーの掲載ページです。  
マーケティング分析、LP構成、デザインカンプ制作、バナー制作までをまとめています。

- URL: https://aktouch.github.io/portfolio/works/schoolbag/
- 主な内容: LPデザイン、バナー、スマホビュー、QR導線

### 2. LP Analytics Demo

LP改善を想定した、簡易ファネル計測シミュレーターです。  
仮想PV、CTAクリック、フォーム到達、送信完了などの行動データを画面上で可視化するデモです。

- URL: https://aktouch.github.io/portfolio/works/LPAnalyticsDemo/
- 主な内容: JavaScriptによるイベント計測、カウンター表示、ファネル改善の可視化

### 3. Future Tech

架空企業サイトを想定したWebページです。  
メインビジュアル、カルーセル、企業紹介、ページトップボタンなど、基本的なLP構成を実装しています。

- URL: https://aktouch.github.io/portfolio/works/futuretech/
- 主な内容: HTML / CSS / jQuery、カルーセル、レスポンシブ対応

### 4. Carousel & Address API Demo

カルーセル表示、郵便番号から住所を自動入力するAPI連携、Google Map表示を組み合わせたデモページです。  
フォーム入力や住所検索など、実務で使われるUIを意識して制作しています。

- URL: https://aktouch.github.io/portfolio/works/Carousel%26AddressAPI_Demo/
- 主な内容: jQueryカルーセル、住所自動入力API、Google Map連携、フォームUI

## 目的

職業訓練や自主制作で作成したWebページを、1つのポートフォリオとして整理し、制作物の意図・実装内容・学習成果が伝わる形で公開することを目的としています。
