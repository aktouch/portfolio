動画を背景にした
Fire pit紹介ページ

既存のアウトドア製品紹介ページに、Adobe Premiere Proで編集した動画を背景として実装しました。 昼から夜、使用前から使用中へと場面をつなぎ、キャンプでFire pitを使う流れが伝わる映像にしています。

  • Adobe Premiere Pro
  • HTML / CSS
  • 制作時間 30min

Implementation

背景動画の実装

HTMLの video 要素でMP4を読み込み、CSSでヘッダー全体に広げています。 動画を背面、見出しを前面に配置することで、映像の上に文字が表示される構成にしました。

HTML / firepit/index.html
<header>
  <div class="bg">
    <video
      class="bg-media"
      autoplay
      muted
      loop
      playsinline
      preload="auto">
      <source
        src="img/firepit_bg.mp4"
        type="video/mp4">
    </video>
  </div>

  <h1>Fire pit</h1>
</header>
CSS / background layout
header {
  position: relative;
  overflow: hidden;
}

.bg {
  position: absolute;
  inset: 0;
  z-index: 0;
}

.bg-media {
  width: 100%;
  height: 100%;
  object-fit: cover;
}

header h1 {
  position: relative;
  z-index: 1;
}

autoplay + muted

ページを開いたときに動画を自動再生するための指定です。

loop

動画終了後に先頭へ戻し、背景映像を繰り返します。

playsinline

スマートフォンでも全画面に切り替えず、ページ内で再生します。

object-fit: cover

縦横比を保ちながら、動画をヘッダー領域いっぱいに表示します。

position: absolute

動画をヘッダー全体に重ね、背景として配置します。

z-index

動画を背面、タイトルなどのコンテンツを前面に表示します。

Editing Process

動画編集から実装まで

Webページの背景として自然に見えるよう、時間帯と使用シーンの変化を意識して素材を並べました。

  1. Step 01

    動画の構成を決める

    「プロダクトの紹介 → キャンプで火を使う場面 → 夜のキャンプ」という流れを設計しました。

  2. Step 02

    素材を並べてカットする

    昼から夜、使用前から使用中へと変化するように素材を並べ、不要な部分をカットしました。

  3. Step 03

    場面切り替えを調整する

    場面のつながりを滑らかにするため、ビデオエフェクトの「イマーシブ」を追加しました。

  4. Step 04

    MP4で書き出してWebへ実装する

    約60秒の動画としてMP4形式で書き出し、VS CodeでFire pit紹介ページの背景に組み込みました。
