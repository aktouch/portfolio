Carousel & Address API Demo

jQuery slickのカルーセルと、郵便番号から住所を自動入力し、取得した住所をGoogleマップで表示するサンプルです。

ZipCode API

郵便番号から住所を自動入力

郵便番号を入力して「住所を検索」ボタンを押すと、都道府県・市区町村・町域が自動で入力されます。

※APIで自動入力されるのは、主に都道府県・市区町村・町域までです。番地や建物名は手入力してください。

Google Map

取得した住所を地図で表示

郵便番号から取得した「都道府県・市区町村・町域」をもとに、Googleマップを表示します。 番地・建物名を入力したあとに入力欄から離れると、より詳しい住所で地図を更新します。

まだ住所は検索されていません。

郵便番号を検索すると、ここに地図が表示されます。
